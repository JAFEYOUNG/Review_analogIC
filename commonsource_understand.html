1. 电阻负载共源极（RD）
Av = −gm1 ( ro1 ∥ RD ) ≈ −gm1 RD = −√2μnCox(W/L)1ID · RD
  • 负载线形态：斜率为 -1/RD 的直线，在 Vout = VDD 处电流归零。
  • 核心矛盾（增益 vs 裕度）：想把电压增益拉高，就必须增大 IDRD；但直流压降 IDRD = VDD − Vout 太大时，会把输入管 M1 压进线性区（掉到黄线左侧拐点），增益反而崩塌。
  • 线性度：负载线本身是纯线性的，失真主要来自 M1 的平方律非线性（ID ∝ Vov2）。
2. 二极管连接负载（1/gm2）
Av = −gm1 ( ro1 ∥ ro2 ∥ 1gm2 ) ≈ −gm1gm2 = −√μn(W/L)1μp(W/L)2
  • 负载线形态：紫色的二次曲线，当 Vout ≥ VDD − |VTHp| 时完全关断（摆幅天花板损失一个阈值电压）。
  • 增益小但很稳：因为分母有个很小的 1/gm2，曲线斜率最陡，增益通常只有 1 ~ 4 倍；但一阶近似下增益只取决于尺寸比，与电流和工艺漂移关系较小。
  • 意外优点：NMOS 平方律与 PMOS 平方律（假设 λ=0）互相抵消，大信号线性度反而最好（只要两者都保持在饱和区）。
3. 电流源负载（M2, ro2）
Av = −gm1 ( ro1 ∥ ro2 ) = −2(λn + λp) Vov1
  • 负载线形态：蓝色曲线在饱和区（Vout ≤ VDD − |Vov2|）几乎是一条极平缓的水平线（斜率仅 −1/ro2）。
  • 超大增益的物理本质：只需极小的直流裕度 |Vov2|（≈ 0.2~0.4V），就换来了极大的交流电阻 ro2。输入只要变动一点点 Δvin，交点 Vout3 就会大幅左右横跳！
  • 缺点与改进：输入线性范围极窄，开环输出对偏置 Vin,DC 和 VB 极其敏感（实际芯片必须加外部负反馈或共模反馈）；若要继续提增益，可用共源共栅（Cascode）进一步把蓝线拉平。

回答视频左上角问题（VG2S2 等于什么？）：
空载时流过 M2 的电流等于 IB，因此 VG2S2 = VTH2 + Vov2（其中 Vov2 = √[2IB / (μnCox(W/L)2)]）。 又因为 M1 的漏极接在节点 X，VD1 = VG2S2，为了保证 M1 不进线性区，要求 Vout ≤ VG2S2 − Vov1（所以基础 NMOS FVF 的高电平输出摆幅受限于 VG2S2）。
图2：精确小信号等效电路（随开关动态点亮）

设计注意事项（稳定性警告）：FVF 环路具有两个主要极点（开环节点 X 极点 1/(rxCx) 与输出节点极点）。若输出端接入过大的负载电容 CL，输出极点向低频移动，极易导致相位裕度不足而出现振铃甚至振荡。

    若使用深 N 阱 NMOS 或把 PMOS FVF 的衬底与源极短接（消除 gmb1 = 0），则理想条件下 Av 极其逼近 1.000；且 M1 电流恒定，VGS1 在大信号摆幅下几乎不变，线性度远超电阻负载和普通电流源负载源随器。
  5. 第五步（进阶厘清）：若真在“闭环状态”从节点 X 实测对地电阻 RX,closed，它等于多少？
    此时允许 vout 随 vx 自由联动（vin=0）。M2 拉低 vout 迫使 M1 向下抽电流，通过联立 vout 的 KCL 可得（记 gΣ = gm1 + gmb1 + 1/ro1 + 1/ro2 + 1/RL）：
    轻载/空载时负反馈把节点 X 的阻抗从 rx 压低为 1/gm2 ∥ roB；而当 RL → 0（即把 vout 短接到地、断开反馈）时，该式自动退化回 ro1 ∥ roB = rx！

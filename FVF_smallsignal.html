回答视频左上角问题（VG2S2 等于什么？）：
空载时流过 M2 的电流等于 IB，因此 VG2S2 = VTH2 + Vov2（其中 Vov2 = √[2IB / (μnCox(W/L)2)]）。 又因为 M1 的漏极接在节点 X，VD1 = VG2S2，为了保证 M1 不进线性区，要求 Vout ≤ VG2S2 − Vov1（所以基础 NMOS FVF 的高电平输出摆幅受限于 VG2S2）。

设计注意事项（稳定性警告）：FVF 内部多了一个高阻节点 X（M2 的栅极）。如果输出端接了很大的负载电容 CL，输出极点往低频移动，极易导致这个两极点反馈环路出现振铃甚至自激振荡！因此驱动大容性负载时通常需要做频率补偿或限制 CL。
四步完成手写推导（期末/面试标准流程）
  1. 第一步：列写节点 X（M1 漏极 / M2 栅极）的 KCL 方程
    把 M1 看作从源极 vout 到漏极 vx 的共栅极（CG）放大器。令 rx = ro1 ∥ roB：
    gm1(vin − vout) − gmb1vout + vx − voutro1 + vxroB = 0  ⇒  vx = (ro1 ∥ roB) · [ (gm1 + gmb1 + 1ro1)vout − gm1vin ]
  2. 第二步：求输出电阻 Rout（令 vin = 0，在 Vout 加测试电压 vt 与测试电流 it）
    从输出端看进去，流入 M1 的电流恰好等于流入 roB 的电流（vx / roB），其余全被 M2 吸走：
    it = gm2vx + vtro2 + vxroB ≈ gm2 · (gm1 + gmb1)(ro1 ∥ roB) · vt  ⇒  Rout = vtit ≈ 1gm2(gm1 + gmb1)(ro1 ∥ roB)
  3. 第三步：求电压增益 Av（接入负载 RL）
    由节点 vout 的 KCL：(gm2 + 1/roB)vx + (1/ro2 + 1/RL)vout = 0，代入 vx 化简得：
    Av = voutvin = gm1 gm1 + gmb1 + 1ro1 + 1/ro2 + 1/RL(gm2 + 1/roB)(ro1 ∥ roB)
    可以看到：负载 RL 的影响被分母上巨大的环路增益 (gm2rx) 缩小了几十倍！
  4. 第四步：为什么说“超级源随器（FVF）”几乎只剩体效应误差？
    若使用深 N 阱 NMOS 或把 PMOS FVF 的衬底与源极短接（消除 gmb1 = 0），则理想条件下 Av 极其逼近 1.000；且 M1 电流恒定，VGS1 在大信号摆幅下几乎不变，线性度远超电阻负载和普通电流源负载源随器。
